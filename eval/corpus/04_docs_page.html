Calibrating widgets

Calibration corrects small offsets that come from manufacturing tolerances and from the mounting position. A widget that is calibrated once keeps its offset across restarts.

Temperature offsets

Place a reference thermometer beside the widget and wait fifteen minutes. Then enter the reference reading on the device page.

Using the calibration command

The same step can be run from the command line:

nexus-cli devices calibrate --device WID-0042 --reference 21.5

nexus-cli devices show --device WID-0042

Humidity offsets

Humidity calibration uses a saturated salt solution. The steps are:

  • Seal the widget and the reference in a container for one hour.
  • Record the reference humidity from the label on the solution.
  • Enter the value on the device page.

Troubleshooting

Offset looks wrong after moving a widget

Calibrate again after any change of mounting position. Offsets do not follow a widget between sites.
